# Instrumento de encuesta para el MVP de COGIT

## Introducción

COGIT es una propuesta de plataforma web educativa para apoyar el aprendizaje del pensamiento computacional mediante misiones y actividades gamificadas. Este instrumento busca conocer las necesidades, dificultades, preferencias y expectativas de estudiantes de primero y segundo semestre respecto de las funcionalidades contempladas para su producto mínimo viable (MVP): misiones, Sudoku, nonogramas, Robot Programmer, seguimiento del progreso, ranking y una comunidad en versión demostrativa.

La encuesta está diseñada para aplicarse a una muestra prevista de 20 estudiantes. Su diligenciamiento toma aproximadamente entre 5 y 7 minutos. La participación es voluntaria y no se solicitan datos que identifiquen personalmente a quien responde. Las respuestas se utilizarían únicamente con fines académicos y para orientar los requisitos del MVP. En esta etapa, el instrumento no ha sido aplicado y no contiene resultados reales.

**Instrucciones:** Lea cada pregunta y seleccione la respuesta que mejor represente su opinión. Cuando se indique “seleccione todas las opciones pertinentes”, puede marcar más de una respuesta. En las escalas, el significado de cada valor se especifica en la pregunta.
